# Parked Experiment Ledger

Updated: 2026-09-02

Status: active scope-control ledger. Parking preserves code, contracts, failed
attempts, manifests, and scientific evidence. It does not reject a method
family and does not authorize reactivation.

## Parking Rule

An experiment is parked when one or more apply:

- it does not directly test C1 or C2;
- it expands the project into an architecture, corrector, detector, or PDE zoo;
- it lacks a qualified reference law, restart, population, or state contract;
- it requires exogenous OOD, online detection, sealed/test access, RL, or broad
  benchmark reproduction;
- it duplicates a closed historical diagnostic; or
- it cannot fit the current two-week critical path.

A parked line re-enters only after the owner selects a concrete claim, the new
attempt receives an appropriate identity/preregistration, all source/data/
population/evaluator bindings are available, and the applicable execution
level is explicitly authorized.

## Diagnostic-Only Items

These are allowed only as frozen offline measurements, not deployed method
families:

- exact manifold distance in ODEs;
- time-/condition-matched kNN distance;
- qualified local-PCA reconstruction residual;
- MMD on a frozen physical feature map;
- physical feature drift; and
- solver-relative defect and trusted tangent/normal or finite-amplitude response;
- fixed-interface predictor gain `q`, corrector gain `rho`, complete-map gain,
  and the qualified `rho q` product; and
- convex-hull membership as a coarse/negative ODE proxy.

The selected B4 operational correctors receive separate method contracts and a
fixed correction schedule. Any additional use that changes a rollout, selects
an online fallback, or triggers correction from an OOD score remains parked.

## Preservation And Recovery

- No code, preregistration, data, checkpoint, result, failed attempt, or
  artifact is deleted because a line is parked.
- Existing historical files and Git evidence retain their original scope. Do
  not reconstruct deleted archives without owner direction.
- Use [MECHANISTIC_DIAGNOSTIC_TRACKER.md](MECHANISTIC_DIAGNOSTIC_TRACKER.md)
  and the exact run ID to recover evidence.
- Future re-entry never reuses an old run identity after a source, population,
  metric, or authorization change.
